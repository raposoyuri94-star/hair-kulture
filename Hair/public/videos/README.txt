Place your hero video in this folder and name it hero.mp4.
The website loads it automatically at /videos/hero.mp4.

Use an MP4 encoded with H.264 for broad browser support. A short,
compressed landscape video works best. It plays muted and loops;
visitors can pause it or enable sound using the video controls.

The existing campaign image stays visible if the video is missing.
To use a different filename, edit src in Hair/components/hero.tsx.
